# Pokedex
O projeto consiste na criação de um sistema de Pokémon para a atividade avaliativa da disciplina de DSW2,
do 2º ano de TII. O sistema permitirá cadastrar treinadores. Cada Pokémon poderá ser treinado por um treinador ou mais, possuir vários movimentos e ter uma ou duas tipagens.
Os movimentos também terão uma tipagem, permitindo relacionar cada movimento ao seu respectivo tipo.
